# Embedded report assets

`bootstrap.min.css` is Bootstrap v5.3.8 from the official `twbs/bootstrap` release:

- Source: `https://github.com/twbs/bootstrap/blob/v5.3.8/dist/css/bootstrap.min.css`
- SHA-256: `d85327d99c7a3ee1f9b5d0500d1370acea3ad2db39c163c2f51f232baedbdede`
- License: MIT; see `bootstrap.LICENSE`

The renderer embeds Bootstrap and the local report assets into one offline HTML file. It does not load a CDN or any other runtime dependency.
